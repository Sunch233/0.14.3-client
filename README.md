# MCPE 0.14.3 Sunch Client

一款专为 **Minecraft PE 0.14.3** 设计的mod客户端。

## 功能 / 特性

- `帧数显示`: 游戏内左上角显示当前fps
- `垂直同步`: 自由开关vsync，解锁帧数限制 (注意: 帧数过高时触碰无法蹲下)
- `游戏内信息显示`: 类似java版WTHIT mod的效果，游戏内顶部显示正在查看的方块、实体信息
- `动态光源`: 字面意思
- `强制疾跑`: 前进时默认疾跑
- `兼容鼠标输入`: 完整安卓鼠标支持
- `更多错误处理`: 在jsonUI、glsl着色器进行解析、编译时出现错误自动报告。避免反复排查
- `json UI 布局调试`: 直观的在游戏内看见各种ui控件的信息，内容，方便更改
